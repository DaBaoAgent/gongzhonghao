# 文风红线（违禁AI味词清单）

校验脚本 `scripts/validate_docx.py` 内置该列表，命中即报错。

## 结构类（口播/推文通用）
- 【 】 方括号小标题
- 镜头切到 / 画面来到
- 划重点 / 说白了 / 接下来 / 总的来说
- 值得注意的是 / 不可否认的是 / 真正重要的是
- 本质上 / 底层逻辑

## 套话类
- 不是A而是B / 不只是A更是B / 与其说A不如说B
- 你觉得呢 / 是不是很震撼
- 点赞、关注（结尾引导语除外，如"欢迎关注XX公众号"）
- 惊艳 / 震撼全场 / 燃爆 / 刷屏

## 标点
- 英文引号 " "（用中文「」或“”）
- 产品卖点行允许用"——"连接（既定风格），正文叙述中避免

## 写作基调
- 先结论后细节；数字用真实资料；形容词最多连用1个
- 每段不超过3句；小节用"◆ 标题"格式
